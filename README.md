# Exercicio.js3 – Consulta de CEP

Este é um projeto simples desenvolvido em **HTML, CSS e JavaScript** que realiza a consulta de um **CEP (Código de Endereçamento Postal)** usando a API pública [ViaCEP](https://viacep.com.br).

## 🚀 Funcionalidades

- Permite ao usuário digitar um CEP e selecionar uma categoria.
- Ao enviar o formulário, a aplicação consulta o CEP.
- Exibe os seguintes dados:
  - Rua (logradouro)
  - Bairro
  - Cidade
  - UF (Estado)

## 📦 Tecnologias utilizadas

- HTML5
- CSS3
- JavaScript (ES6)
- API ViaCEP
